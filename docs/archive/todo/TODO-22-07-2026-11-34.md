# Emerald Utilities System Standardisation & Infrastructure Overhaul

## Goal

Transform Emerald Utilities from a collection of working modules into a unified, maintainable desktop application.

Focus on:

- UI standardisation
- Architecture consistency
- Database correctness
- Data reliability
- Developer documentation
- Security hardening
- Removing legacy inconsistencies

Do NOT add unnecessary features.

Do NOT rewrite working systems unless required.

The objective is:

"Every part of Emerald Utilities should feel like it belongs to the same application."

# Platform UI Rules

Each platform adapter provides:

{
 id,

 name,

 capabilities,

 composerFields,

 limits
}


Example:

{
 id:"instagram",

 capabilities:{
    text:false,
    images:true,
    video:true
 },

 composer:{
    requiresMedia:true,
    supportsTags:true
 }
}


The UI dynamically builds the composer.

Do not hardcode platforms.
