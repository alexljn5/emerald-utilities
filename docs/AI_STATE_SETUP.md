# AI State Setup

After cloning the repository, copy the public templates to create your local private files:

```text
src/database/character-sheets.example.js
  -> src/database/character-sheets.js

src/database/ai-context.example.js
  -> src/database/ai-context.js
```

Edit the copied files with your private/local AI data.

The real files are intentionally Git-ignored and must never be committed. Only the `.example.js` templates belong in the public repository.
